# Parallel & Distributed Computing (PDC) - Lab Assignment 2

This repository contains the complete solution for PDC Lab Assignment 2, demonstrating thread-safe data structures, concurrent execution models, and parallel algorithm optimizations in Java.

## Project Structure & Sub-Modules

- **Q1_TradeEngine**: Complex Event Processing (CEP) and order dispatching via object-oriented polymorphism.
- **Q2_PacketAuditor**: Zero-Trust network payload verification using custom array-backed LIFO Stack and FIFO Queue.
- **Q3_TelemetryEngine**: Concurrent execution engine managing asynchronous telemetry workers and log processors.
- **Q4_ForkJoinPortfolio**: Data-parallel financial risk assessment leveraging `ForkJoinPool`, `RecursiveTask`, and `RecursiveAction`.
- **Q5_SensorGrid**: Concurrency control in IoT grid monitors using explicit synchronization and `ReentrantReadWriteLock`.
- **Q6_CatalogBenchmark**: High-throughput benchmark comparing thread safety overhead between `Collections.synchronizedMap` and `ConcurrentHashMap`.
- **Q7_CacheBenchmark**: Thread-safe synchronized LRU Cache implementation with custom eviction mechanics using `LinkedHashMap`.
